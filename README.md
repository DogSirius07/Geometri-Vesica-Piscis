# 🌌 Projeto 05.05 - Nossa Frequência

Este repositório contém uma experiência digital interativa criada para celebrar o primeiro mês de namoro (iniciado em 05/05) e oficializar nossa união no Dia dos Namorados.

## ✨ Tecnologias Utilizadas
*   **HTML5/CSS3:** Estrutura e estilização mística.
*   **JavaScript:** Lógica de contador em tempo real e gatilho de surpresa.
*   **Geometria Sagrada:** Arte visual baseada em psicologia e harmonia.

## 🚀 Como visualizar
Acesse a página oficial através do link gerado pelo GitHub Pages.
